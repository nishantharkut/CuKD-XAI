3.2. Evaluation Metrics
A set of evaluation metrics including the accuracy (ACC), precision (PR), recall (RE), and f1-score
are utilized to evaluate and compare the results of proposed intrusion detection model. They were
used because they produced comparable results and frequently used in the machine learning ﬁeld for
evaluating and comparing its models. These performance evaluation metrics are computed as:
Accuracy (ACC) = (TP + TN) ⁄ (TP + FP + TN + FN)
(7)
Precision (PR) or Positive Predictive value (PPV) = TP/(TP + FP)
(8)
Recall (RE) (True Positive Rate) (Sensitivity) = TP ⁄ (TP + FN)
(9)
F1-Score = 2*((Precision * Recall)/(Precision + Recall))
(10)
Speciﬁcity, Selectivity or True Negative Rate (TNR) = TN ⁄ (TN + FP)
(11)
False Positive Rate (FPR) = FP/(FP + TN)
(12)
False Negative Rate (FNR) = FN/(FN + TP)
(13)
where TP, TN, FP, and FN are the true positive, true negative, false positive, and false negative,
computed from the confusion matrix.
