Experiment setup
The experiments for the IDS model were conducted on a system equipped with Ubuntu 20.04 LTS as the operating 
system, ensuring compatibility with various ML libraries. The system was configured with 16 GB of RAM and 
a 512 GB ROM, allowing efficient handling of large datasets. For processing, an Intel Core i7-9700K processor 
was used, coupled with a 1 TB SSD for faster data access and a 2 TB HDD for additional storage. To support 
the execution of ML models, several Python libraries were utilized, including scikit-learn for traditional 
algorithms, xgboost for extreme gradient boosting, lightgbm for Light Gradient Boosting and pandas, 
numpy along with matplotlib for implementing data reading, numerical computing, and visualization on 
Jupyter Notebook, Anaconda Navigator environment. This setup provided a robust environment to conduct 
model training, testing, and performance evaluation effectively.
