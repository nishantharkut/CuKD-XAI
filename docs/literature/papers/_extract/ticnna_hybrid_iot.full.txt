ABSTRACT The swift growth in ubiquitous connectivity, such as 5G and 6G, cloud computing, which
enables data-driven automation and increases efficiency across industries, gave rise to the Internet of Things.
This proliferation significantly expands the network attack surface, making IoT-based networks increasingly
vulnerable to a multitude of attacks. To mitigate the attacks, Intrusion detection systems are developed. While
developing the IDS, a primary challenge is the data collection of attack patterns and their training. The
data collected is often massive, heterogeneous, and, critically, imbalanced. Training conventional models
on such imbalanced data typically leads to poor performance, particularly in overlooking minority attack
classes during multi-class classification. Our proposed system directly addresses this challenge of data
imbalance. We introduce a hybrid technique, the Transformed Image Generative Adversarial Network
(TIGAN), that generates high-fidelity attack samples and is then used to augment underrepresented attack
classes, complemented by downsampling of overrepresented ones. The balanced data allows our lightweight
deep learning model, Transformed Image Convolutional Neural Network (TICNN), to achieve robust attack
detection. The experimental TICNN-based IDS delivers a faster detection time and detection accuracy
of 99.56% at the macro level, which showcases its strong capability to identify diverse attacks, sporadic
minority classes, in challenging IoT settings.

training to minimize the duration of training and enhance the

model, trained on this balanced data, is evaluated with the
CICIoT2023, CICIDS2017 IDS datasets, covering multiple

Advanced machine/deep learning-based intrusion detec-

still a lot of research issues which were not yet resolved:
RQ1 While techniques like sampling [2], [6] and Generative
Adversarial Networks (GANs) [7] are being actively
explored to address data imbalance, how can we
develop DL models that achieve both high accuracy
and efficiency when classifying imbalanced data,
particularly for rare or minority attack sub-classes [8]?
RQ2 The synthetic data generation done by previous
research has a synthetic bias. How can we design a
sampling method and GAN that effectively generate
correct amount of synthetic data?
RQ3 With growing dataset sizes and model complexity,
how can we ensure that DL-based IDS remain com-
putationally efficient for real-time deployment without
compromising classification accuracy, especially when
dealing with high-dimensional data and multiple attack
classes [9]?
The primary contributions of this work, which differentiate
it from existing literature that often focuses on majority-class
binary classification and high computational IDS models not
feasible for existing scenarios, are as follows: (1) We propose
a dense 2D RGB latent space transformation for tabular
data that achieves a 4× theoretical memory compression,
addressing the memory bottlenecks of traditional IDS.
(2) We introduce the TIGAN framework, which utilizes an
adaptive IQR-based thresholding rule that helps mitigate
the effects of synthetic bias associated with traditional
GAN-based techniques of oversampling and undersampling
RGB image data. (3) We develop the TICNN architecture.
The lightweight model employs Global Average Pooling
to achieve 1.81 million parameters while attaining 99.56%
macro accuracy. In contrast to past efforts that relied solely
on optimizing ensembles, we focus on optimizing both the
granularity of detection for smaller minority subclasses and
computational efficiency to facilitate IoT deployment at the
edge of the network.
II. LITERATURE REVIEW
Researchers have developed anomaly-based Intrusion Detec-
tion Systems (IDS) that are robust and have success in
attack detection in IoT networks. However, traditional IDS
measures often fall short when faced with the unique
challenges of IoT environments, such as device heterogeneity,
resource limitations, and the sheer volume of data generated.
Consequently, researchers are shifting more towards Machine
Learning (ML) and Deep Learning (DL) techniques to
develop more adaptive and effective IDS [9], [10].
A significant body of research focuses on applying various
DL architectures to enhance IDS performance. Early work
included the development of optimized Convolutional Neural
Networks (CNNs) combined with Transfer Learning to
secure the Internet of Vehicles (IoV) [1]. Transfer learning,
which allows pre-trained models to be fine-tuned for specific

To further this research, foundational enhancements were
made, including the creation of new, large-scale datasets like

also focused on generally enhancing AI-based NIDS using
Generative Adversarial Networks (GANs) [4] and improving

Building on these foundations, subsequent work has
applied more sophisticated models. Researchers have demon-
strated the combined power of CNN and Long Short-Term
Memory (LSTM) networks for boosting IoT security using
recent datasets [13], while further advancements in the IoV
domain have included the use of tokenization alongside
DL models to improve detection accuracy [14]. These
studies collectively highlight a trend towards leveraging
sophisticated deep learning models to build more accurate
and context-aware intrusion detection systems [9].
Recent advancements have also focused on optimizing
machine learning frameworks to handle the complexity of
IoT network traffic. To address this, researchers created
better machine learning frameworks based on their ability to
handle high-dimensional data. These enhanced frameworks
generally use PCA techniques in addition to some methods
for reducing the number of features so that they perform
better on a wide variety of tasks by removing unnecessary
complexity from the feature-extraction process [15], [16].
Similarly, ensemble strategies have shown effective results;
for instance, a tree-driven intelligent security system, which
utilizes bagging ensembles to increase detection rates in
diverse IoT environments [17]. To further improve upon the
accuracy of these ensemble models, techniques based upon
evolutionary optimization methods have been implemented.
A perfect example of this is an ensemble learning approach
using a butterfly optimization method to dynamically opti-
mise weight parameters in order to enhance the strength
and effectiveness of an intrusion detection system against
different attack patterns [18]. Furthermore, recent studies
have emphasized the importance of complex system security
and intelligent detection in industrial contexts. For instance,
research in industrial reliability engineering [19] and expert
systems for security [20] highlights the need for robust
anomaly detection in interconnected environments. Our
proposed TICNN framework aligns with these trends by
providing an efficient, image-based detection mechanism that
is particularly suited for the high-stakes security requirements
of industrial IoT (IIoT) systems.
However, a major problem in training effective IDS
models is the inherent class imbalance in network traffic
datasets, where malicious activities are often rare compared
to benign traffic. This imbalance can bias models, leading to
poor detection rates for critical, albeit infrequent, attacks.
To counter this, various strategies have been explored. Tradi-
tional sampling techniques, such as SMOTE and ADASYN,
have been evaluated for their effectiveness in IoT datasets [6],
and specialized methods like Weighted Optimized SMOTE
(WOSMOT) have been integrated into DL pipelines for
detecting specific attacks like DDoS [2].
GANs have become increasingly recognized as a powerful
tool for generating high-quality synthetic minority-class
data. Researchers have developed specialized GAN archi-
tectures like TMG-GAN [5] and CTGAN [9] specifically
for imbalanced IDS datasets. Other work has utilized
GANs for unsupervised anomaly detection, with models
like FlowGANAnomaly learning network flow patterns to
identify deviations [21]. In parallel, adversarial techniques
have continued to evolve with novel methods like ProGen,
which focuses on generating projection-based adversarial
examples [22].
The latest research pushes the boundaries further with
advanced hybrid models. These include approaches combin-
ing Swin Transformers and LSTM with transfer learning [23].
Furthermore, hybrid models combining Autoencoders (AE)
with Wasserstein GANs (WGAN) have been proposed to both
extract representative features and generate realistic synthetic
attacks, achieving superior performance on established
benchmarks like NSL-KDD and CIC-IDS2017 [7], [24].
This dual role of GANs fortifying defenses by generating
synthetic data while simultaneously simulating advanced
threats to probe for vulnerabilities positions them as a key
technology in the ongoing cybersecurity arms race. The
ability of GANs to learn complex data distributions, even
demonstrated in fields like SAR-to-Optical image transla-
tion [25], underscores their potential impact on network
security. However, the GAN techniques used can give rise to
synthetic, biased training because the imbalance ratio among
the classes is very high, a challenge that remains a focus of
ongoing research.
III. PROPOSED FRAMEWORK
The proposed work first converts the dataset into images and
then addresses the data imbalance issue using the proposed
Tabular-Image Generative Adversarial Network (TIGAN)
hybrid sampling method for image generation. This balanced
dataset is used to train the proposed Transformed Image
Convolution Neural Network (TICNN) model to achieve
high results while maintaining performance on extensive IoT
datasets.

B. PROPOSED TIGAN AND HYBRID-SAMPLING
FRAMEWORK THAT RESOLVED RQ2
Various dataset-balancing techniques and algorithms are used
to generate synthetic data. Two primary approaches for
handling class imbalance in tabular data are oversampling
and undersampling. However, these methods come with
significant limitations in highly imbalanced scenarios. In the
case of oversampling, especially when the minority-to-
majority class ratio is extremely low, the IDS (Intrusion
Detection System) model tends to become synthetic-biased—
favoring the artificially generated samples over real ones,
which compromises generalization and detection accuracy.
On the other hand, undersampling in such cases can result
in up to 99% data loss, discarding valuable information
from the majority class and degrading model performance.
To address this issue, we proposed a hybrid sampling
algorithm that finds a threshold value and generates new
images or removes excess image samples by defining a
threshold value. To determine a suitable threshold T for
class balancing in our dataset, we calculate several key
statistical measures across the class distributions. Let C =
{c1, c2, . . . , cn} represent the set of classes, each with an
image count N(ci) for class ci.

which serves as a central measure of our class distribution.

IV. PERFORMANCE EVALUATION AND RESULTS
The experiments were conducted on a system equipped
with an AMD Ryzen Threadripper Pro processor featuring
12 cores, 62.7 GiB of memory, and an NVIDIA GeForce
RTX 3070 GPU. The primary dataset used for evaluation
is the CICIoT2023 dataset, which contains over 46 million
attack samples distributed across 33 attack classes and
1 benign class, as visualized in Fig. 6. The dataset is highly
imbalanced, posing a substantial challenge for accurate and
fair classification. This makes it well-suited for evaluating the
robustness and effectiveness of deep learning-based intrusion
detection systems. To further assess the generalizability of the
proposed model, the CICIDS2017 dataset was also employed.
CICIDS2017 comprises 14 attack classes and 1 benign
class represented in Fig. 7, offering a broad spectrum of
contemporary network threats including DDoS, PortScan,
Botnet, and more. The inclusion of both datasets—each

2) HYBRID SAMPLING TECHNIQUE AND TIGAN ANALYSIS
Oversampling and undersampling are established methodolo-
gies for mitigating class imbalance in datasets. Oversampling
techniques, such as Random Oversampling, SMOTE (Syn-
thetic Minority Oversampling Technique), and ADASYN,
aim to augment the instances of the minority class to achieve a
more balanced dataset. Although oversampling can enhance
model performance in scenarios of imbalance, it carries the
risk of overfitting, particularly with random oversampling,
as it merely replicates existing minority instances, poten-
tially leading the model to be overly attuned to specific
samples. Conversely, undersampling involves the reduction
of majority class instances through approaches like Random
Undersampling, Tomek Links, and NearMiss. This method
can streamline the dataset and expedite training times but
may inadvertently discard vital information concerning the
majority class, which could detrimentally impact the model’s
ability to generalize. Hybrid sampling strategies, which
integrate both oversampling and undersampling techniques,
offer a compelling alternative by capitalizing on the strengths
of both approaches while mitigating their respective weak-
nesses. By generating synthetic samples for the minority class
while concurrently minimizing redundancy in the majority
class, hybrid methods preserve the dataset’s diversity. This
balance aids in reducing both overfitting and underfitting
risks, ultimately making hybrid sampling more potent for
enhancing model performance on imbalanced datasets while
safeguarding data integrity and generalization capabilities.
Analysis: SMOTE is simpler to use but more prone
to overfit in sparse regions; both ADASYN and SMOTE
perform well with tabular data. Although ADASYN has
severe imbalances, it adapts to sample density. In every
scenario, including photographs, TIGAN works remarkably
effectively by combining over- and under-sampling. Its
hybrid design allows it to handle different data distributions
while minimizing overfitting and preserving the majority
class’s diversity. TIGAN is a dependable solution for
unbalanced datasets since it can generate an arbitrary amount
of synthetic images, even though it requires more processing
power but utilizes less memory as compare to ADASYN and
SMOTE.
The results presented in Table 10 indicate that under-
sampling as a strategy does not yield effective performance
in the context of the datasets evaluated (CICIoT2023 and
CICIDS2017). For both datasets, the accuracy obtained
through undersampling is extremely low, with values of
0.02% for CICIoT2023 and 0.00% for CICIDS2017. This
is in stark contrast to the higher accuracy obtained with
oversampling and hybrid sampling strategies, which pro-
duced 96.5% and 98.0% accuracy for the CICIoT2023 and
CICIDS2017 datasets, respectively.Undersampling reduces
the amount of data available for training by eliminating
minority class samples, which can lead to a significant loss of
crucial information and account for its subpar performance.
When there is a large class imbalance, undersampling
exacerbates the imbalance problem and reduces the model’s
capacity to generalize. This is shown by the noticeably lower
accuracy rates for undersampling in both datasets.However,
oversampling and hybrid sampling techniques help to bal-
ance the class distribution and improve performance while
maintaining the model’s ability to learn from both majority
and minority classes. Despite being slightly more precise
than oversampling, hybrid sampling requires less processing
power and in this case it performs well because imbalanced
ratio is high.

K-Fold Cross-Validation, which splits the dataset into ‘‘K’’
equal-sized pieces, or folds, is a widely used technique
for evaluating the efficacy and generalizability of machine
learning models. In each iteration, K-1 folds are used to train
the model, while the remaining fold is used for validation.
Throughout the K iterations of this procedure, each fold
serves as the validation set once. The final performance
metric is then averaged over all K iterations to provide a more
precise evaluation of the model’s anticipated performance on
unknown data. K-Fold Cross-Validation offers the significant
advantage of reducing bias and variation because each data
point is used for both training and testing, ensuring a more
thorough evaluation of the model’s performance.

E. TIGAN: GENERATIVE QUALITY & STATISTICAL
VALIDATION
The reliability of the samples generated from the TIGAN is
assured through performing both qualitative and quantitative
evaluations on the samples created from this generator. Most
previous Work related to the generation of Synthetic Data
for use in Tabular ID systems has relied upon Classification
Accuracy determined after training as an indirect method for
assessing quality, however this method does not typically
identify mode collapse or low diversity of generated data.
The authors believe that this is the first effort which has
involved utilizing industry standard computer vision metrics
to confer reliability upon the quality of synthetic Tabular to
Image IoT Traffic Data, and therefore sets a new standard for
the evaluation of the Cleanliness of Synthetic Data generated
for use in Intrusion Detection Systems.
1) VISUAL FIDELITY
In the analysis we conducted of TIGAN’s output with
9 randomly selected sample images as shown in Fig. 2.,
we performed a side-by-side comparison against 9 synthetic
images generated through TIGAN. The results of our
visual inspection demonstrate that TIGAN can replicate the
complex textural patterns and color distributions seen in
actual network traffic imagery. Additionally, the synthesized
network traffic imagery show similar spatial correlations to
those of the actual minority class samples. This indicates that
TIGAN has learned to model the underlying feature manifold
of the minority class, instead of simply memorizing data
points from that class.
2) QUANTITATIVE METRICS (FID & IS)
We used the Fréchet Inception Distance (FID) and Inception
Score (IS) to measure this fidelity objectively. While IS
assesses the diversity and clarity of the generated samples
(higher is better), FID measures the difference between the
feature distributions of real and synthetic images (lower is
better). According to our evaluation results, TIGAN’s FID
score of 11.24 was considerably lower than that of typical
GAN implementations, which typically range between 20 and
40 on complex datasets. Additionally, the model obtained a
Inception Score (IS) of 4.15, indicating that TIGAN does not
produce generic noise but rather a variety of attack patterns
that are sufficiently different for the classifier to discriminate.
This statistical validation demonstrates that high-quality,
statistically representative synthetic data are responsible for
the performance improvements seen in TICNN.
F. LIMITATIONS OF IMAGE-BASED IDS
An image created from a table-based dataset results in greater
efficiency, though processing effort is required to achieve
this benefit. For instance, packet size represents a field in a
table and has a specific interpretation based on the network
attribute it represents while the image does not maintain that
same reference. Therefore, referring to the image, a neural
network will still identify patterns, but tracking a predicted
output back to the network packet field that resulted in that
prediction is much more complex through a convolutional
neural network than it is when using a decision tree model.
Additionally, regarding the practical deployment of
TIGAN, there is a trade-off between the ‘offline’ training cost
and ‘online’ detection benefits. While training TIGAN for
minority subclasses requires approximately 360–800 seconds
per class, this is a one-time computational investment.
The resulting balanced TICNN model provides ultra-low
latency packet detection (1.5–2.9 ms), which is critical
for real-time IoT security. However, several limitations
remain. First, the current approach relies on feature-rich
network headers; its effectiveness may decrease when dealing
with heavily encrypted traffic where payload inspection is
impossible. Second, the model is currently designed for static
training cycles. In online learning scenarios, where new
IoT threats evolve dynamically, the system would require
periodic retraining or a more adaptive incremental learning
architecture to maintain its edge.
V. CONCLUSION
In summary, this research illustrates how converting large,
multidimensional IoT datasets into two-dimensional images
can help alleviate memory limitations by enabling four
times more effective data compression, thereby allowing
more rapid data processing. Furthermore, the use of the
TIGAN-generated hybrid sampling method combined with
a lightweight TICNN provides nearly perfect (over 99%)
macro-level classification across more than 33 attack types.
Therefore, this framework delivers a scalable real-time IDS
(Intrusion Detection System) with the capability to accurately
identify infrequent attacks while minimizing the impact on
IoT (Internet of Things) edge device resource constraints.
