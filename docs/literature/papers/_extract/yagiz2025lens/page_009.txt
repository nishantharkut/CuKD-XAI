3.2.1. Missing Value Handling
We adopt a hybrid strategy to address missing entries:
1. Imputation: For minor gaps, we replace missing values with the mean
or median, preserving overall statistical distributions.
2. Exclusion: For records with extensive missingness, we remove them
to minimize noise and bias.
This approach retains the majority of the data while limiting the distortion
introduced by imputation.
3.2.2. Feature Encoding and Transformation
Categorical and non-numerical features must be translated into numerical
forms for downstream ML models:
• One-hot encoding: Converts nominal categories into binary indicator
variables.
• Ordinal encoding: Maps ordered categories to integer values when a
natural order is relevant.
We choose the encoding method on a feature-by-feature basis, prioritizing
minimal information loss.
