The XGBoost model [44] is chosen for the AI-based IDS
due to its efﬁciency, scalability, and ability to handle imbal-
anced training datasets, along with its reduced computation
resource requirements compared to deep learning models.
XGBoost’s advanced regularization minimizes overﬁtting,
and its gradient boosting framework handles large train-
ing datasets effectively. Compared to traditional machine
learning models such as Random Forests or Support Vec-
tor Machines (SVM), XGBoost requires lower training time
and provides better control through hyperparameter tuning.
While deep learning models like neural networks can achieve
high accuracy, they often require large amounts of training
data and computational resources. XGBoost offers a balance
by providing good detection performance with lower com-
putational overhead. For datasets like CIC-DDoS2019 and
CICIoT2023, this balance is crucial for achieving high per-
formance without excessive computational costs.

the conﬁguration that yields the best cross-validation perfor-

ization. The learning_rate governs the contribution of each

To compare the XGBoost model performance before and
after feature reduction, we use ﬁve metrics: Accuracy, Preci-
sion, Speciﬁcity, Recall, and F1 Score. These metrics allow
for a comprehensive evaluation of our approach’s effective-
ness beyond mere accuracy. For instance, Precision measures
the model’s ability to correctly identify malicious samples,
while Recall evaluates its capability to detect all malicious
samples. Speciﬁcity shows the model’s ability to avoid false
positives, and F1 Score provides a balance between Precision
and Recall.
4.2 Evaluation scenarios, results, and analysis
We evaluate our XAI-based IDS framework using one dataset
from CIC-DDoS2019 and three datasets from CICIoT2023,
each containing benign trafﬁc samples as well as malicious
trafﬁc samples of one of the following speciﬁc DDoS attack
types: Portmap, SYN Flood, HTTP Flood, and Slowloris.
These attacks are highly effective and represent both volu-
metric (e.g., Portmap, SYN Flood, HTTP Flood) and slow
(e.g., Slowloris) attack types, which pose signiﬁcant chal-
lenges for an IDS due to their differing trafﬁc patterns.
Additionally, we use the 5G PFCP dataset, which represents
control-plane attacks in 5G networks. It focuses on two spe-
ciﬁc attack types: PFCP Session Deletion and PFCP Session
Establishment. These attacks rely on signaling protocols and
packet-level manipulations rather than volumetric trafﬁc pat-
terns seen in data plane attacks. This results in a smaller
feature set, often limited to protocol-speciﬁc attributes like
session counters or message types, which can make it difﬁ-
cult to distinguish malicious activity from normal operations
