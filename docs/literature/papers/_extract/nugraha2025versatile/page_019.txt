4.2.4 Efﬁciency of the local explanations
In this subsection, we evaluate the efﬁciency of SHAP and
LIME local explanations by comparing their execution times
for two scenarios: using all features and using the reduced
feature set obtained through the ﬁrst stage of our frame-
work. All experiments were conducted on a workstation
with an AMD Ryzen 7 3800X 8-core CPU, 32 GB RAM,
and an NVIDIA RTX 3060 GPU (12 GB VRAM). For
LIME, we used a single CPU core with 5000 perturba-
tions per instance to provide consistent timing comparisons.
While the reported measurements reﬂect this speciﬁc hard-
wareconﬁguration,theframework’sdesign—particularlythe
dimensionality reduction stage and the use of a lightweight
XGBoost model—ensures that detection accuracy is pre-
served even on lower-speciﬁcation systems. The primary
difference in such environments would be in explanation gen-
eration time, especially for LIME, which is more sensitive to
CPU performance than SHAP’s TreeExplainer.
