Feature selection
The feature selection process reﬁnes the dataset by identi-
fying and retaining only the most relevant features, which
improves model accuracy and reduces computational com-
plexity. This research employs a multi-step approach to
feature selection, combining correlation analysis, mutual
information, and Principal Component Analysis (PCA) to
ensure the ﬁnal feature set is both relevant and efﬁcient.
