Explanation Methods
We now provide additional overview of the different saliency methods that we assess in this work. As described
in the main text, an input is a vector x ∈Rd. A model describes a function S : Rd →RC, where C is the number
of classes in the classiﬁcation problem. An explanation method provides an explanation map E : Rd →Rd that
maps inputs to objects of the same shape. Each dimension then correspond to the ‘relevance’ or ‘importance’ of
that dimension to the ﬁnal output, which is often a class-speciﬁc score as speciﬁed above.
