2) SHAP PLOT FOR A PARTICULAR TEST SET (LOCAL)
Among the most well-liked and simple-to-use tools for local
representation in model interpretability are the SHAP force
and waterfall plots. The contribution of each feature to a
single ML model prediction is visually explained by the
SHAP force diagram. It draws attention to the base value,
which is usually displayed in the center of the plot and
represents the predicted forecast prior to the consideration
of any data. The anticipated value is displayed on the plot
once feature contributions have been taken into consideration.
The contribution of each attribute is shown as an arrow: blue
arrows indicate negative impacts that drive the prediction
below the base value, while red arrows indicate positive
influences that push the prediction above it. These arrows’
lengths indicate the relative importance of each feature,
giving a clear, sequential explanation of how the model
arrived at its conclusion.
The SHAP waterfall plot conveys the same information
as the SHAP force plot but does so in a two-dimensional
format. In this plot, E[f (x)] represents the base value or
the average predicted value, serving as the starting point.
