4) RANDOM FOREST (RF)
One popular ensemble learning method for both classification
and regression applications is Random Forest. During the
training phase, this approach builds many decision trees,
and the final output is based on the mean forecast of each
individual tree or the mode of the classes. Random Forest
improves prediction accuracy and stability by combining the
predictions from several trees. The integration of randomness
in data sampling and feature selection contributes to the
construction of different trees, hence limiting the risk of
overfitting. It also offers estimates of feature relevance,
which helps with feature selection and can handle huge,
high-dimensional datasets. All things considered, Random
Forest is a strong and flexible ensemble technique that is
well-liked across a range of ML applications due to its
excellent accuracy and resilience.
5) K-NEAREST NEIGHBORS (KNN)
KNN is a straightforward, non-parametric, and lazy learning
method that predicts the result based on the k-nearest
data points in the feature space. It is utilized for both
regression and classification tasks. The algorithm runs by
storing all accessible data points and, for all new input,
calculating the distance to all training data points, sorting
these distances, selecting the k closest points, and utilizing
them for prediction. It uses neighborly majority voting for
categorization and neighbor average computation of values
for regression. KNN’s main benefits are its simplicity, ease
of use, adaptability, and short training period. Nevertheless,
it can be memory- and computationally-intensive, and it
is susceptible to data scaling and unimportant aspects. All
things considered, KNN is a useful technique for a variety of
applications, especially when the data quantity is reasonable
and the feature significance is obvious.
E. EXPLAINABLE AI (XAI)
The term Explainable AI (XAI) is a collection of approaches
and procedures designed to increase human comprehension
and transparency of artificial intelligence (AI) system out-
puts. Ensuring that users can comprehend and interpret AI
models, like ensemble approaches, is the aim of explainable
AI. Two frameworks have been used to explain the planned
task.
1) LOCAL INTERPRETABLE MODEL-AGNOSTIC
EXPLANATIONS(LIME)
The method known as LIME (Local Interpretable Model-
agnostic Explanations) is used to analyze and comprehend
the predictions made by intricate ML models. By using an
interpretable model to approximate it locally, it provides an
explanation for any black-box model’s predictions. LIME
offers many explainable models, each specific to each input
point, that closely mimic the behavior of the original model.
The explainable model guarantees that its predictions will be
quite close to the black-box model around this input point
[36]. LIME is used in this proposed effort to better understand
the behavior of the model and to determine the rationale
behind particular predictions.
2) SHAPLEY ADDITIVE EXPLANATIONS(SHAP)
The SHAP framework clarifies how various features con-
tribute to a model’s output, making it possible to evaluate
predictions made by ML models. SHAP values, which have
their roots in cooperative game theory, offer a way to
comprehend how each attribute affects the prediction for a
certain instance [34], [35]. It can be difficult to describe a
model’s reliability when it is complex. Although accuracy is
a useful performance metric, it doesn’t explain how the model
learns or generates predictions. In order to solve this, SHAP
provides visualization tools that illustrate how each feature
in a dataset contributes to the prediction, explaining the
results of any ML method. There are several SHAP explainers
available; the explainers used in this proposed work are Tree
and Kernel. The results of this proposed study are explained
via a series of plots provided by SHAP, which allow for an
in-depth examination of the properties of the model.
F. STREAMLIT
Streamlit is an application framework that makes it simple
to create online applications for ML. It has excellent com-
patibility with the main Python packages that are frequently
used for data processing and visualization in ML. Because
of this interoperability, developers may easily create visually
appealing and interactive applications to present their ML
models and outcomes [37].
