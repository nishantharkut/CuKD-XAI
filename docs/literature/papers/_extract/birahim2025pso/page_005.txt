3) STANDARDIZATION
Standardization, often referred to as z-score normalization,
is a preprocessing method used in statistics and ML to
change a dataset’s features so that their means and standard
deviations are both one. This method helps to lessen the
negative effects on the performance of some algorithms,
therefore it is especially useful when working with data that
has different scales [29]. The formula for standardization is
as follows:
z = x −µ
σ
(1)
here, µ is the feature mean, z is a standardized value, and x
is the initial feature value. The feature’s standard deviation
is σ. Given the varied range of data inside the WSN-DS
dataset, scaling becomes vital for assuring effective analysis
and model performance. By adopting standardization, all
features are brought to the same scale, ensuring that each
feature contributes equally to the model and preventing any
single feature from overwhelming others. In the end, this
procedure improves the accuracy and performance of the ML
algorithms used on the dataset by preserving its balance and
integrity.
