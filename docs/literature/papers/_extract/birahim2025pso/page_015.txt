3) SHAP SUMMARY PLOT FOR IMPORTANCE OF FEATURES
(GLOBAL)
The SHAP summary plot is a visualization tool that shows
how different attributes impact an ML model’s output. In this
two-dimensional graphic, the vertical and horizontal axes,
respectively, reflect the feature names and the influence of
the SHAP values. The SHAP values along the horizontal
axis indicate each feature’s impact on the model’s output.
A centerline divides these SHAP values; values to the right of
the centerline suggest that the feature increases the expected
value, while values to the left suggest that it decreases it.
The titles of the features are positioned in descending order
of influence along the vertical axis, with the most important
features at the top. The plot also uses color to indicate
feature value, with red indicating greater importance and blue
indicating less relevance. It is simpler to see which features
have the greatest influence on the model’s predictions thanks
to the color coding.
Figure 14 represents the SHAP summary plot for the
Normal class of a test dataset. The plot reveals that the
feature ‘‘dist_CH_To_BS’’ is the most important feature
for the Normal class, as evidenced by its widest spread
of SHAP values, indicating its significant impact on the
model’s outcome for that class. The feature also shows that
most of the higher SHAP values are on the left side of the
centerline, suggesting that as the value of ‘‘dist_CH_To_BS’’
increases, it tends to have a negative impact on the prediction.
Other important features include ‘‘DATA_R,’’ ‘‘ADV_S,’’

4) SHAP SUMMARY PLOT OF THE VIOLIN DISTRIBUTION
FOR IMPORTANCE OF FEATURE (GLOBAL)
The influence and density of features in the output of an ML
model are shown by the SHAP summary plot with violin
distribution. It has a horizontal and vertical axis and is a
two-dimensional plot, just like the typical SHAP summary
plot. The vertical axis provides a list of feature names, and
the horizontal axis displays the SHAP values, which show
how each feature affects the model’s prediction. However,
instead of showing the exact position of the SHAP values,
the violin plot displays the density of these values at different
positions, offering a visual representation of how densely the
SHAP values are concentrated in certain areas. This helps
to understand not just the magnitude of a feature’s impact,
but also how consistently that impact occurs across different
predictions.
