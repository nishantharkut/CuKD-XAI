To validatively compare our proposed TIGAN framework
with traditional balancing techniques, we attempted to
apply SMOTE and ADASYN directly to the raw tabular
(CSV) data. However, as highlighted in our computational
resource analysis, performing oversampling on the massive
CICIoT2023 dataset (over 42 million records) in its tabular
format led to complete memory exhaustion (Out of Memory
errors) on standard high-performance workstations. The
tabular expansion required to balance 33 classes resulted in
an exponential increase in RAM usage, rendering standard
SMOTE and ADASYN computationally infeasible for the
full dataset.
In contrast, our proposed methodology converts these
high-dimensional tabular vectors into compact 2D RGB
images before generation. This transformation, combined
with TIGAN’s batch-wise generative process, reduced
RAM utilization by approximately 8 times compared
to the estimated requirements of tabular oversampling.
Consequently, TIGAN not only provides superior synthetic
data fidelity but is also the only computationally viable

3) K-FOLD CROSS VALIDATION ANALYSIS ON DATASET
USING TICNN MODEL
K-Fold Cross-Validation, which splits the dataset into ‘‘K’’
equal-sized pieces, or folds, is a widely used technique
for evaluating the efficacy and generalizability of machine
learning models. In each iteration, K-1 folds are used to train
the model, while the remaining fold is used for validation.
Throughout the K iterations of this procedure, each fold
serves as the validation set once. The final performance
metric is then averaged over all K iterations to provide a more
precise evaluation of the model’s anticipated performance on
unknown data. K-Fold Cross-Validation offers the significant
advantage of reducing bias and variation because each data
point is used for both training and testing, ensuring a more
thorough evaluation of the model’s performance.

and validation. This is especially crucial when there may
be more classes than others, as this could skew the model’s
results. For our investigation, we divided the dataset into five
