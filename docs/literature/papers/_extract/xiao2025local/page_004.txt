In summary, this study introduces a resource-aware
and explainable intrusion detection framework for WSNs,
achieving high detection accuracy while maintaining com-
putational efﬁciency. The proposed system is robust against
diverse attack types and tailored for the constrained environ-
ments typical of WSN deployments.
2 Data collection
To generate the dataset and gather the necessary data from the
transmitted and received packets within the WSN, a low-cost
monitoring service is required. On the other hand, all rele-
vant network data should be captured to aid in the detection,
classiﬁcation, and prevention of various potential assaults. In
this study, to disperse the load across sensor nodes, each sen-
sor participates in the monitoring process and must be able
to monitor a collection of its neighbors. The task was deter-
mining the optimal number of nodes to observe by a sensor
node in order to monitor all network sensors. The dataset was
gathered from a published study, which included an exper-
imental process for monitoring, with 374,661 samples, and
23 attributes were extracted to identify each node’s status in
the network [19]. The dataset is listed in Table 2.
Figure 1 illustrates the correlation matrix among the vari-
ables. Regarding the relationship between the Attack Type
and the input features, the variable “Is CH” exhibits a strong
positive correlation with the output, whereas “JOIN S” shows
a strong negative correlation. Additionally, several other
variables display varying degrees of positive and negative
correlations, which had a key role in guiding the process of
feature selection and prioritization for subsequent analysis.
Table 3 presents the description of features alongside their
Variance Inﬂation Factor (VIF) scores for both the initial
and reduced feature vectors. VIF analysis was conducted to
detect multicollinearity among predictors, with higher VIF
values indicating stronger correlation with other variables.
In the initial feature vector, most variables had acceptable
VIF values (typically below the critical threshold of 10),
except for “JOIN S” (VIF = 37.1710) and “SCH R” (VIF
= 27.8604), which showed extremely high multicollinearity.
These two features were therefore removed in the reduced
feature vector to improve model stability and avoid redun-
dancy in prediction. After removal, the VIF scores of the
remaining features generally decreased, indicating reduced
multicollinearity. For example, “Dist To CH” decreased from
3.5336 to 2.3373, and “DATA S” dropped from 4.3942 to
2.7054. The reductions suggest that the elimination of highly
collinear variables had a positive effect on the overall qual-
ity of the feature set. The retained variables, such as “Is
